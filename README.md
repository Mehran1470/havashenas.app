# هواشناسی هرمزگان (havashenas.app)

اپ اندروید «هواشناسی هرمزگان»: داشبورد زنده‌ی آب‌وهوا و جزرومد شهرهای استان هرمزگان، همراه با ویجت صفحه‌ی اصلی، اعلان دائمی و Live Notification (Now Bar) برای اندروید ۱۶.

اپ با [Capacitor](https://capacitorjs.com) ساخته شده: رابط کاربری یک صفحه‌ی HTML در پوشه‌ی `www` است و بخش‌های بومی اندروید (ویجت، اعلان، سرویس) در پوشه‌ی `widget` هستند.

## امکانات

- وضعیت لحظه‌ای هوا، پیش‌بینی ساعتی و ۷ روزه برای شهرهای هرمزگان
- جزرومد و نقشه‌ی هواشناسی زنده (Windy)
- حالت ساده و حالت پیشرفته (GPS، پس‌زمینه‌ی زنده‌ی وابسته به هوا، کارت‌های UV، باد، فشار، موج و کیفیت هوا)
- حالت دقت حداکثری (ترکیب چند مدل هواشناسی)
- ویجت صفحه‌ی اصلی با چند تم رنگی
- اعلان دائمی هوا
- **Live Notification / Now Bar** (اندروید ۱۶ به بالا): کپسول کوچک با حباب شیشه‌ای هوا، دما با یک کلمه‌ی انگلیسی، و باد و احتمال بارش

## Live Notification (Now Bar)

- روی اندروید ۱۵ و پایین‌تر، همان اعلان دائمی معمولی نمایش داده می‌شود و چیزی خراب نمی‌شود.
- در تنظیمات اپ (هر دو حالت) کلید **Live Notification (Now Bar)** برای روشن و خاموش کردن وجود دارد و زیرش وضعیت نوشته می‌شود.
- روی گوشی‌های سامسونگ (One UI 8)، ممکن است لازم باشد گزینه‌ی **Live notifications for all apps** در تنظیمات توسعه‌دهنده روشن باشد. این تنظیم دست سامسونگ است و از داخل اپ قابل تغییر نیست.
- اعلان‌ها از کانال بدون نشان عددی (badge) استفاده می‌کنند.
- آیکون حباب‌ها عکس‌های آماده‌اند (`widget/bubble_*.png`): ابر، نیمه‌ابری، خورشید، باران، رعدوبرق، برف، ماه و باد.

## منبع داده

- [Open-Meteo](https://open-meteo.com): هوا، دریا و کیفیت هوا
- Open Tide API: جزرومد (منبع دوم در حالت دقت حداکثری)
- [Windy](https://www.windy.com): نقشه‌ی هواشناسی

## ساختار پروژه

| مسیر | توضیح |
| --- | --- |
| `www/` | رابط کاربری (`index.html`)، `manifest.json`، `sw.js` و آیکون‌ها |
| `widget/` | کد اندروید: ویجت، اعلان، سرویس، Live Update و فایل‌های ظاهری |
| `widget/WeatherNotificationService.java` | سرویس اعلان دائمی؛ داده را می‌گیرد و اعلان را می‌سازد |
| `widget/LiveUpdateNotification.java` | ساخت اعلان قابل ارتقا برای Now Bar (فقط اندروید ۱۶+) |
| `widget/WeatherBubble.java` | رسم حباب (پشتیبان، اگر عکس آماده پیدا نشود) |
| `widget/CityWidgetPlugin.java` | پلی‌بین صفحه‌ی وب و بخش بومی اندروید |
| `widget/MainActivity.java` | فعالیت اصلی، فاصله‌ی نوار وضعیت و درخواست مجوز |
| `widget/manifest_*.xml` | مجوزها و سرویس‌هایی که هنگام بیلد به Manifest اضافه می‌شوند |
| `.github/workflows/build-apk.yml` | بیلد خودکار APK |

## ساخت APK

بیلد با GitHub Actions انجام می‌شود و به اندروید استودیو نیازی نیست:

1. ورک‌فلو **Build APK** با هر push به `main` اجرا می‌شود، یا از تب **Actions** با دکمه‌ی **Run workflow** (می‌توان هر برنچی را انتخاب کرد).
2. پس از اتمام، فایل `havashenas-apk` را از بخش **Artifacts** همان اجرا دانلود کنید.

ورک‌فلو مراحل زیر را انجام می‌دهد: نصب Capacitor، ساخت پروژه‌ی اندروید، کپی فایل‌های `widget/` داخل آن، افزودن مجوزها و سرویس‌ها به Manifest و در نهایت `./gradlew assembleDebug`.

### نیازمندی‌ها

- Node.js 22 و Capacitor 8
- Java 21
- `minSdk` برابر 24 (اندروید ۷ به بالا)، `compileSdk` و `targetSdk` برابر 36

## نکته‌ها

- APK فعلی با کلید debug امضا می‌شود؛ تا زمانی که کلید امضای ثابت تنظیم نشده، نصب نسخه‌ی جدید روی قبلی ممکن است نیاز به حذف نسخه‌ی قدیمی داشته باشد.
- سایت مستقل پروژه در ریپوی جدا قرار دارد و با این ریپو هم‌گام نیست.
